# Spec: Messaging Landing Page — Finnon

## Tono

Profesional pero cálido. Frases cortas, lenguaje cotidiano. Enfoque positivo: Finnon no juzga ni restringe, acompaña y da visibilidad. El componente emocional es clave — objetivos, no presupuestos; ilusión, no culpa.

## Notas para implementación

- **Screenshots:** resolver los problemas del feedback original — más grandes, sin cards envolventes, mostrar tanto versión móvil como web.
- **Sección colaborativa:** acompañar con screenshots reales de la pantalla "Tu Cuenta" con las barras de contribución visibles. Es la prueba tangible de la promesa.
- **Sección personalización:** mostrar ejemplo de categorías custom y la pantalla de objetivos/simulador.
- **No mencionar** la ausencia de conexión bancaria como feature ni como limitación. Si el usuario pregunta, se responde. En la landing no existe como tema.
